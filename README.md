# 🌐 Meus Sites Favoritos

Projeto desenvolvido como parte das atividades da **Agenda 12 - Programação Web I** do Curso Técnico em Desenvolvimento de Sistemas (EaD - Centro Paula Souza / ETEC).

---

## 📌 Sobre o Projeto

O objetivo desta página web simples é armazenar e apresentar uma lista com os meus sites favoritos do dia a dia, aplicando os conceitos fundamentais de estruturação em **HTML5** aprendidos na disciplina.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** (Linguagem de Marcação)
* **Estrutura semântica:** Uso de tags como `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<h1>`, `<figure>`, `<figcaption>`, `<img>` e `<a>`.

---

## 💻 Sites Listados

1. **Google**
2. **YouTube**
3. **Netflix**
4. **Disney+**

---

## 🛠️ Como Executar o Projeto

1. Clona ou transfere este repositório para o teu computador.
2. Garante que as imagens (`.png` / `.webp`) estão na mesma pasta que o ficheiro `index.html`.
3. Dá duplo clique no ficheiro `index.html` para abri-lo em qualquer navegador web (Chrome, Edge, Firefox, etc.).
